# Flashcards

### Démarrage
Node.js : Assurez-vous que Node.js est installé sur votre machine grâce à la commande `node -v`.<br>
Faite aussi attention au fichier `.env` qui doit être configuré selon votre image docker.<br>
Dirigez vous ensuite dans le dossier src puis effectuez la commande `npm i` puis `npm run dev` pour lancer le projet à l'adresse entrée dans le `.env`. L'adresse par défaut est `localhost:3333`. 

### Objectif pédagogique
L'objectif principale de ce projet était de nous familiariser avec la notion de MVC (Modèle-Vue-Contrôleur). Pour ce faire, nous avons utiliser les différents composants du framework web AdonisJs afin d'avoir également des notions de javascripts en général. Nous avons également eu l'autorisation d'utiliser une intelligence articielle pour nous aider. L'objectif de ce geste n'est pas de demander à une IA de tout faire à notre place, mais de commencer à utiliser les outils qui hébergeront notre avenir. Nous avons beaucoup utiliser des termes utilent pour notre futur comme les différents type de requète, CRUD etc...


### Objectif produit
L'application est un site web hébergé dans une image docker qui permet à l'utilisateur d'étudier différente thématiques. C'est la notion de [Flashcards](https://en.wikipedia.org/wiki/Flashcard) qui est implémenté dans le site, des cartes qui ont des questions et qui cache une réponse à l'arrière. Le site offre l'ajout, la modification ou encore la suppression des différent "decks" créés par l'utilisateur. Dans ces decks, l'étudiant pour également ajouter, modifier ou encore supprimer des cartes à sa guise. Il est ensuite possible d'éxercer ces différent deck avec un compteur de réponse juste / fausse selon le choix de l'éxerceur.

### Bilan
Lors de ce projet, j'ai réussi a implémenter tout les objectif produit.  
Je pense avoir acquis plus de connaissance que je pensais. Il reste cependant encore pleins de choses à découvrir car l'avenir du site peut contenir des foncionnalitées comme : des comptes, différentes difficultées, un classement de decks par catégories. 

### Utilisation de l'IA
Durant ce projet, je me suis beaucoup aidé de l’intelligence artificielle. Cet outil m’a permis de mieux comprendre les erreurs que je rencontrais, notamment en les retranscrivant dans un langage plus clair et compréhensible. Grâce à cela, il m’a été plus facile d’identifier les problèmes et de progresser dans le développement du site.

L’IA a également produit environ 95 % du style de mon site ainsi que la majorité de la structure HTML. Elle m’a donc principalement servi d’assistant pour certaines parties techniques et répétitives du travail.

Cependant, l’entièreté de la logique du site ainsi que tout le code JavaScript ont été entièrement réalisés par moi-même. Ce sont donc des éléments que j’ai conçus et développés personnellement. Je serais également capable d’expliquer tout le code fourni par l’IA, ainsi que bien sûr le code que j’ai écrit moi-même.

Je ne pense pas avoir utilisé l’IA d’une manière qui me rendrait dépendant. Je suis convaincu que, si on me le demande, je pourrais refaire ce projet depuis le début sans son aide. L’intelligence artificielle a seulement été utilisée pour des tâches que je considère comme laborieuses, mais qui restent tout à fait réalisables manuellement.

### Conclusion
Le projet était intéressant et m'a bien appris la notion de MVC et des requète http. AdonisJS est un framework compliqué à prendre en main mais facile à manipuler dès qu'on commence à bien comprendre les notions de bases.
